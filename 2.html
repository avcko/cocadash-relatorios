2. API rate limits: Yahoo Finance e alguns endpoints de histórico ficam em timeout após 4–5 queries. Dados históricos de 15 dias parcialmente estimados via suportes técnicos (MA50, MA200) conhecidos. Impacto: analytic de momentum em 15 dias menos preciso.
3. Dados de futuro indisponíveis: Dot plot da Fed (mediana de juros final 2026, 2027) expirou (última reunião 18/09/2026). Decisão do BoJ estimada em 18/09, fora da janela de coleta. Impacto: consenso de taxas de juros refere-se ao anterior (junho); novo consenso será conhecido amanhã.
4. Funding rates de pequenas exchanges: Agregado Bybit + OKX cobre ~60% do volume perpetual. Pequenas exchanges (Deribit, Kraken futures, Huobi) não incluídas (falta de API aberta). Impacto: posicionamento long/short pode estar enviesado para operadores Ásia.
5. Amostragem one-shot: Relatório é snapshot 17/09 10:19 BRT. Volatilidade intraday não capturada. Preços mudam a cada minuto; teses de today/15d assumem suportes/resistências conhecidos às 10:19, não ao fechamento (16:00 BRT stocks, 24/7 cripto). Impacto: breakouts intraday podem invalidar teses sem sinalização aqui.
6. Dados de on-chain (Glassnode): Histórico TVL, long/short distribution vem de agregadores de terceiros. Não é verificado contra ledgers de cada exchange. Amostragem pode ter delays <2h. Impacto: dados ~2h de idade potencialmente; posições podem ter mudado.
7. Nenhuma estimativa silenciosa: Campos marcados "dado indisponível" significam API devolveu erro, timeout ou bloqueio (403). Não foram preenchidos com proxies, médias ou palpites. Teses que dependem desses dados têm risco estrutural de invalidação se o dado real for diferente.
8. Timezone: Toda a coleta foi normalizada para BRT (UTC-3 / Brasília). Horários de agenda comparados contra fuso de cada país (EUA = EST/EDT, Japão = JST, EU = CET). Risco de off-by-one se transição de horário de verão entre cotas.
